# Security policy

MCP Guard is a static configuration checker. It does not execute MCP servers or claim to certify a deployment.

## Reporting a vulnerability

Do not disclose secrets, exploit steps against a live system, or sensitive configuration in a public issue. Use GitHub's private vulnerability reporting for this repository when available, or contact the repository owner through GitHub to request a private channel. Include only a sanitized reproduction, affected version, and impact summary.

Reports about a false positive or a missing rule belong in the public issue forms when they contain no sensitive data.

## Supported versions

The latest tagged release on the `master` branch is the supported version. Security fixes may be backported when the affected behavior is present in a recent release.
